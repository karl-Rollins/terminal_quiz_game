## ⚙ Installation & Setup

Open the folder terminal_quiz_game in your IDE(eg vscode)
All code is written in the quiz.sh file.

In the terminal;
-run the code chmod +x quiz.sh to give permission to the file to be executed
-then run the code ./quiz.sh. to start
